## Fortnite keybinds

Open **Settings → Keyboard Controls** (the arrow keys icon) and bind **Building Edit** to <kbd>F</kbd>. [Epic Games settings guide](https://www.epicgames.com/help/c-34254770/c-81/a10326284)

> [!IMPORTANT]
> Bind **Select Building Edit** (**« Sélectionner la modification »** in French) to <kbd>G</kbd>, then apply your changes.

## Run the macro

1. Download and run **zkiz Macro.exe**. The combo starts disabled every time you launch it.
2. Press <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>F8</kbd> to enable it. A brief on-screen message shows the current state.

## Controls

| Input | What happens |
| --- | --- |
| **Hold F** while enabled | Sends **F** immediately, then holds **G** after **20 ms**. |
| **Release F** | Releases **G**. |
| **Ctrl + Alt + F8** | Toggles the combo. When disabled, **F** works normally. |

The combo is active system-wide when enabled. To close it, right-click its icon in the Windows notification area and choose **Exit**.
